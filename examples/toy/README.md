# Toy inputs

Synthetic inputs generated by `lara-skills toy-data --output examples/toy --seed 20261011`: a 240-skill dictionary, 20 occupations, four yearly posting files, 60 technology descriptions with relevance judgments, the application configuration `lara_app.json` and `toy_manifest.json` with content hashes of every table. See `docs/toy_dataset.md` for how the tables are built and what the quickstart produces.

To run the pipeline on a copy of these inputs:

```bash
lara-skills quickstart --workspace lara_toy_workspace     # regenerates the same inputs in a fresh workspace
```

or copy this directory somewhere and run `lara-skills build --config <copy>/lara_app.json`. Outputs are written next to the configuration under `data/processed/` and `artifacts/`, which git ignores.
